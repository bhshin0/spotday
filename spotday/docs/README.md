# Design Documentation

This directory contains design assets and documentation for the SpotDay app.

## Figma Prototypes

The `figma_proto` directory contains the latest design prototypes, including:

- Welcome/Onboarding screens
- Activity selection
- Restaurant preferences
- Itinerary display
- Map integration

## Design Decisions

### Core Features
1. **Time-Aware Scheduling**
   - Opening hours consideration
   - Travel time buffers
   - Activity duration estimates

2. **Location-Based**
   - Currently focused on San Francisco
   - Map integration planned
   - Travel time calculation

3. **User Preferences**
   - Budget consideration
   - Activity type preferences
   - Food preferences

## Future Design Plans
