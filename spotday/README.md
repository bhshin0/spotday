# SpotDay

An Android app that automatically builds personalized itineraries based on user preferences, time constraints, and location.

## Project Structure

```
spotday/
├── spotday-app/          # Android app code
├── docs/                 # Documentation and design assets
│   ├── figma_proto/     # Figma prototypes
│   └── README.md        # Design documentation
└── README.md            # This file
```

## Features (Planned)

- Automated itinerary building
- Location-based recommendations
- Time-aware scheduling
- Budget consideration
- Map integration
- Opening hours awareness
- Travel time calculation

## Current Status

This is a prototype focusing on the core scheduling logic with:
- Fixed 4-hour duration
- San Francisco location
- Sample museum visit
- Sample restaurant visit
- Basic time window management
- Opening hours consideration

## Getting Started

1. Clone the repository
2. Open the project in Android Studio
3. Build and run the app

## Development

The app is built using:
- Kotlin
- Android Jetpack
- Google Maps API (planned)
- Places API (planned)
